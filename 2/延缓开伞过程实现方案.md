# 延缓开伞过程实现方案

## 1. 目标

在不破坏出舱、减速伞和稳降阶段连续性的前提下，实现以下目标：

1. 延后主伞开始充气的时间；
2. 增加主伞从半充气状态到完全充气的持续时间；
3. 降低主伞开伞瞬间的速度突变和开伞冲击；
4. 保留参数可调能力，便于后续进行多组工况仿真。

本方案针对当前项目中的主伞整理与主伞充气阶段。当前主伞阶段对应：

```text
Python:
    2/airdrop_py/mainchute_stages.py
    zhusan_straight()
    zhusan_chongqi()
    ode45_stage6()

MATLAB:
    airdrop_simulation.m
    ode45_stage5
    ode45_stage6
```

## 2. 当前开伞模型

主伞充气阶段使用三个时间节点：

```text
t1：第一次充气结束，主伞达到 khalf 对应的面积；
t2：第一次充气结束后的等待时间结束，开始第二次充气；
t3：第二次充气结束，主伞达到完整面积。
```

当前 MATLAB 参数定义为：

```matlab
mainchute.k_ks    = zhs_p(17);  % 第一次充气参数
mainchute.n_ks    = zhs_p(18);  % 第二次充气参数
mainchute.StepOpen = zhs_p(19); % 两次充气间隔时间
```

Python 中对应为：

```python
MainChute.k_ks
MainChute.n_ks
MainChute.step_open
```

当前默认值为：

```text
k_ks     = 23.5
n_ks     = 4.3
StepOpen = 5.0 s
```

### 2.1 第一次充气时间

当前模型中：

```text
t1 = k_ks * sqrt(khalf * CA) / V1
```

其中：

```text
CA = 主伞阻力系数 × 主伞特征面积
V1 = 主伞充气阶段初始速度
```

增大 `k_ks` 会使第一次充气过程变慢，主伞面积达到 `khalf` 的时间变长。

### 2.2 两次充气间隔

当前模型中：

```text
t2 = t1 + StepOpen
```

增大 `StepOpen` 会延长主伞保持半充气面积的时间，但不会改变第一次充气速度，也不会改变第二次充气本身的速度。

### 2.3 第二次充气时间

当前模型中：

```text
t21 = n_ks * (
    sqrt(CA) - sqrt(khalf * CA)
) / V2
```

其中 `V2` 为进入第二次充气阶段时的速度。

增大 `n_ks` 会使主伞从半充气状态到完全充气的时间变长，从而降低第二次充气过程的陡峭程度。

## 3. 推荐实现策略

当前需求是不改变输入输出格式，只让开伞响应更平滑、结果曲线更易观察。因此建议优先采用“内部增加阻尼”的方案，保持现有 `zhs_p` 19 个参数和输出数据列不变。

需要明确：阻尼不能改变模型中预先计算的 `t1`、`t2`、`t21`、`t3` 时间节点。它的主要作用是抑制速度、加速度和开伞力的突变，使结果视觉上更平滑，并可能间接延长系统达到稳定状态的时间。

### 3.1 首选方案：增加内部阻尼，不改变输入输出

当前 Python 主伞阶段已经存在内部阻尼常数：

```python
STAGE6_SPEED_DAMPING = 0.1
STAGE6_ANGULAR_DAMPING = 0.02
```

其中 `STAGE6_SPEED_DAMPING` 已经用于 `ode45_stage6()` 的速度微分方程：

```python
dy[3] = ... - STAGE6_SPEED_DAMPING * y[3]
```

建议先将其改为较小范围内的可调常数，例如：

```text
基准：0.10
平滑方案A：0.15
平滑方案B：0.20
平滑方案C：0.30
```

该参数只在代码内部调整，不增加 `zhs_p` 长度，不改变 Excel 输入格式，也不改变输出列和输出数组结构。

建议不要一开始使用过大的阻尼。阻尼过大可能导致：

```text
车辆速度被过度压低；
主伞充气阶段的位移和高度变化失真；
阶段末端速度与稳降阶段衔接不自然；
开伞力峰值虽然降低，但总响应变得过慢。
```

### 3.2 阻尼的推荐实现方式

阻尼应作为气动响应的数值平滑项，而不是修改主伞面积分段函数。推荐保留现有充气面积模型，仅在主伞充气阶段的速度和姿态响应中增加阻尼。

速度阻尼建议使用相对速度形式，避免在不同初速度工况下效果差异过大：

```python
relative_speed = y[3] - velocity_start
dy[3] = physical_acceleration - damping * relative_speed
```

如果当前结果表现为开伞瞬间姿态角变化过快，可增加角速度阻尼。角速度阻尼应作用于姿态角速度的积分或姿态后处理环节，不能直接修改角度输出：

```text
角度状态保持原有物理定义；
只对角速度响应增加衰减；
避免直接对输出曲线做事后滤波。
```

当前 Python 代码中已经有角速度阻尼入口：

```python
STAGE5_ANGULAR_DAMPING = 0.02
STAGE6_ANGULAR_DAMPING = 0.02
```

主伞整理和主伞充气阶段姿态角后处理位于：

```text
2/airdrop_py/mainchute_stages.py
zhusan_straight()
zhusan_chongqi()
```

当前姿态角和角速度的更新流程为：

```python
tw -= vehicle.izz * STAGE6_ANGULAR_DAMPING * angular_velocity[i - 1]
angular_acceleration = tw / vehicle.izz
angular_velocity[i] = angular_velocity[i - 1] + angular_acceleration * dt
angle_vehicle[i] = angle_vehicle[i - 1] + angular_velocity[i - 1] * dt
```

该形式等价于在力矩方程中增加与角速度反向的阻尼力矩：

```text
M_damping = - Izz * c_omega * omega
```

其中：

```text
Izz      = 车辆俯仰转动惯量
c_omega  = 角速度阻尼系数
omega    = 当前俯仰角速度
```

因此当前不需要新增输入输出参数，也不需要改动结果列，只需要扫描内部常量 `STAGE5_ANGULAR_DAMPING` 和 `STAGE6_ANGULAR_DAMPING`。

如果只调整 `STAGE6_ANGULAR_DAMPING`，只能衰减主伞充气阶段已经开始后的角速度；但充气阶段初始角速度来自主伞整理阶段末端。若开伞瞬间姿态角变化过快，应同步调整：

```text
STAGE5_ANGULAR_DAMPING：降低进入主伞充气阶段前继承的角速度；
STAGE6_ANGULAR_DAMPING：降低主伞充气阶段内的角速度响应。
```

推荐扫描值：

```text
基准：STAGE5=0.02，STAGE6=0.02
方案A：STAGE5=0.08，STAGE6=0.08
方案B：STAGE5=0.20，STAGE6=0.20
方案C：STAGE5=0.50，STAGE6=0.50
方案D：STAGE5=1.00，STAGE6=1.00
```

建议先试 `0.50`。如果姿态角尖峰仍明显，再增加到 `1.00`；如果姿态角响应明显滞后、接近被压平，则回退到 `0.20`。

角速度阻尼的主要观察指标：

| 指标 | 预期变化 |
|---|---|
| 俯仰角速度峰值 | 明显降低 |
| 俯仰角曲线斜率 | 更平滑 |
| 俯仰角最终值 | 不应大幅偏离基准 |
| 主伞充气阶段停止时间 | 不应异常提前或延后 |
| 开伞力峰值 | 可能小幅变化，但不应作为主要调节目标 |

如果只想让姿态角曲线好看，优先同步调整 `STAGE5_ANGULAR_DAMPING` 和 `STAGE6_ANGULAR_DAMPING`；如果同时希望速度、开伞力曲线变平滑，再配合调 `STAGE6_SPEED_DAMPING`。

### 3.3 第二阶段：只调整现有开伞参数

如果增加阻尼后仍需要增加实际开伞持续时间，可以在不改变输入输出格式的情况下，直接调整现有参数：

| 参数 | 作用 | 建议 |
|---|---|---|
| `StepOpen` | 延长两次充气之间的等待时间 | 阻尼效果不足时优先调整 |
| `n_ks` | 延长第二次充气过程 | 用于降低第二次充气斜率 |
| `k_ks` | 延长第一次充气过程 | 需要降低首次充气速度时调整 |

建议先固定：

```text
khalf = 0.16
主伞面积、主伞数量、质量和阻力系数保持不变
```

先进行以下参数组对比：

```text
基准组：k_ks=23.5，n_ks=4.3，StepOpen=5.0
方案A：角速度阻尼=0.20，速度阻尼=0.10，k_ks=23.5，n_ks=4.3，StepOpen=5.0
方案B：角速度阻尼=0.50，速度阻尼=0.10，k_ks=23.5，n_ks=4.3，StepOpen=5.0
方案C：角速度阻尼=1.00，速度阻尼=0.10，k_ks=23.5，n_ks=4.3，StepOpen=5.0
方案D：角速度阻尼=0.50，速度阻尼=0.20，k_ks=23.5，n_ks=4.3，StepOpen=5.0
```

以上数值仅作为仿真初始扫描点，不能直接作为最终工程参数。最终值应根据开伞冲击、最低高度和落速约束确定。

### 3.4 备用方案：增加显式延迟参数

如果后续需求变成“主伞整理完成后，先保持伞面积不变一段时间，再开始第一次充气”，仅增加阻尼和调整 `StepOpen` 不够，此时再增加显式的主伞开伞延迟参数：

```text
deploy_delay：主伞开始第一次充气前的延迟时间，单位 s
```

建议定义有效充气时间：

```text
t_open = max(t - deploy_delay, 0)
```

随后所有充气面积计算均使用 `t_open`：

```text
若 t_open <= t1：
    Sm = ks * t_open / t1
若 t1 < t_open <= t1 + StepOpen：
    Sm = ks
若 t_open > t1 + StepOpen：
    进入第二次充气过程
```

这样可以实现：

```text
主伞整理完成
    -> 延迟 deploy_delay
    -> 第一次充气
    -> 等待 StepOpen
    -> 第二次充气
    -> 完全充气
```

## 4. Python 修改方案

### 4.1 参数结构修改

当前 `MainChute` 位于：

```text
2/airdrop_py/models.py
```

建议新增字段：

```python
deploy_delay: float = 0.0
```

由于当前 `MainChute` 使用 `@dataclass(frozen=True)`，应在构造 `MainChute` 时完成参数校验，禁止出现负数：

```python
if deploy_delay < 0.0:
    raise ValueError("deploy_delay must be non-negative")
```

### 4.2 输入参数兼容策略

当前 `zhs_p` 固定为 19 个参数，最后三个参数分别为：

```text
zhs_p[16] = k_ks
zhs_p[17] = n_ks
zhs_p[18] = StepOpen
```

推荐采用向后兼容方式：

```text
zhs_p 长度为 19：deploy_delay = 0.0
zhs_p 长度为 20：zhs_p[19] = deploy_delay
```

这样旧版 Excel 和旧版调用方式仍可继续使用，新版 Excel 可以开启显式延迟。

需要同步修改：

```text
2/airdrop_py/defaults.py
2/airdrop_py/models.py
2/airdrop_py/excel_bridge.py
2/airdrop_py/mainchute_stages.py
```

### 4.3 充气面积计算统一

当前 `mainchute_stages.py` 中，`ode45_stage6()` 和 `zhusan_chongqi()` 的第二次充气边界表达式不完全一致：

```python
# ode45_stage6 使用 t3 = t2 + t21
elif t <= t3 and t21 > 0.0:
```

而 `zhusan_chongqi()` 后处理使用：

```python
elif t <= t2 + t1:
```

这里应统一为同一个结束时间：

```python
t3 = t2 + t21
```

建议抽取一个公共函数，避免 ODE 和后处理各自复制一套分段逻辑：

```python
def mainchute_inflation_state(
    t: float,
    t1: float,
    step_open: float,
    t21: float,
    area: float,
    khalf: float,
) -> tuple[float, float]:
    """Return effective area and area growth rate."""
```

该函数返回：

```text
Sm：当前有效充气面积
Dsm：有效面积变化率
```

`ode45_stage6()`、`zhusan_chongqi()` 和开伞力后处理全部调用该函数。

### 4.4 有效时间接入方式

在 `ode45_stage6()` 中：

```python
effective_t = max(t - mainchute.deploy_delay, 0.0)
```

使用 `effective_t` 代替当前直接使用的 `t`。

在 `zhusan_chongqi()` 的开伞面积、开伞力和 `ca_values` 后处理中，也必须使用相同的：

```python
effective_t = max(t - mainchute.deploy_delay, 0.0)
```

注意：不能只修改 ODE，不修改后处理，否则输出的主伞面积、阻力和开伞力曲线会与积分状态不一致。

## 5. MATLAB 修改方案

如果 MATLAB 仍作为对照基准，也应同步修改：

```text
airdrop_simulation.m
```

建议增加：

```matlab
mainchute.DeployDelay = 0;
```

在 `ode45_stage6` 中：

```matlab
t_open = max(t - mainchute.DeployDelay, 0);
```

将下列逻辑中的 `t(i)` 替换为 `t_open`：

```matlab
if t_open <= t1
elseif t_open <= t2
elseif t_open <= t3
else
end
```

MATLAB 与 Python 必须保持以下定义一致：

```text
t1、t2、t21、t3 的计算公式一致；
deploy_delay 的单位均为秒；
第二次充气结束边界均使用 t3 = t2 + t21；
面积变化率 Dsm 的分段公式一致。
```

## 7. 验证指标

每组参数至少输出以下指标：

| 指标 | 说明 |
|---|---|
| `t1` | 第一次充气结束时间 |
| `t2` | 第二次充气开始时间 |
| `t3` | 主伞完全充气时间 |
| 主伞有效面积曲线 | 检查分段是否连续 |
| 主伞阻力曲线 | 检查延迟期间是否错误产生主伞阻力 |
| 开伞力峰值 | 评价开伞冲击 |
| 开伞力峰值出现时刻 | 判断冲击是否被推迟 |
| 车辆速度变化 | 检查减速过程是否符合预期 |
| 主伞阶段结束高度 | 检查是否满足最低高度约束 |
| 稳降阶段初始速度 | 检查阶段交接是否连续 |

重点检查以下连续性：

```text
主伞整理阶段末端速度
    = 主伞充气阶段初始速度

主伞整理阶段末端姿态角
    = 主伞充气阶段初始姿态角

主伞充气阶段末端状态
    = 稳降阶段初始状态
```

## 8. 测试用例

### 8.1 默认兼容测试

使用原有 19 参数 `zhs_p`，确认：

```text
程序可以正常运行；
deploy_delay 自动取 0；
输出数组维度不变；
阶段停止时间没有异常跳变。
```

### 8.2 延迟测试

设置：

```text
deploy_delay = 2.0 s
```

确认：

```text
deploy_delay 之前主伞有效面积保持为 0；
deploy_delay 之前不产生主伞充气阻力；
第一次充气开始时间相对基准延后约 2 s；
其他阶段仍能正常交接。
```

### 8.3 延长充气测试

分别增大：

```text
STAGE6_ANGULAR_DAMPING
STAGE6_SPEED_DAMPING
StepOpen

```

确认对应变化：

```text
STAGE6_ANGULAR_DAMPING 增大：俯仰角变化更平滑，角速度峰值降低；
STAGE6_SPEED_DAMPING 增大：速度曲线更平滑，开伞冲击降低；
StepOpen 增大：半充气保持时间增加；
```

至少覆盖：

```text
StepOpen = 0

```

## 9. 验收标准

实现完成后应满足：

1. 旧版 19 参数输入不受影响；
2. 新增 `deploy_delay` 后，延迟期间主伞面积和主伞阻力符合预期；
3. `STAGE5_ANGULAR_DAMPING` 和 `STAGE6_ANGULAR_DAMPING` 增大后，俯仰角曲线更平滑，角速度峰值降低；
4. Python ODE 计算与后处理使用同一套充气分段逻辑；
5. MATLAB 与 Python 的 `t1`、`t2`、`t21`、`t3` 定义一致；
6. 增大延迟或充气时间参数时，主伞完全充气时间单调增加；
7. 开伞力峰值不出现非物理尖峰；
8. 主伞阶段与稳降阶段的状态能够连续交接；
9. 仿真总时间足够覆盖新的 `t3`，否则应提示增加 `sim_p[0]`。

## 10. 最终建议

建议当前先执行以下最小改动，不增加输入输出参数：

```text
1. 保持 zhs_p 仍为 19 个参数；
2. 先同步扫描 `STAGE5_ANGULAR_DAMPING` 和 `STAGE6_ANGULAR_DAMPING`，建议从 0.20 到 1.00；
3. 同步扫描 `STAGE6_SPEED_DAMPING`，建议从 0.10 到 0.20；
4. 修正 Python ODE 与后处理中的 t3 边界不一致；
5. 对比开伞力峰值、速度曲线、姿态曲线和主伞阶段结束高度；
6. 如果只是要姿态更顺，不必增加 `deploy_delay`；
7. 只有在确实需要“开始充气前等待”时，才增加 `deploy_delay`。
```

当前更适合采用“内部阻尼 + 现有 `StepOpen`/`n_ks` 参数”的方案：

```text
内部阻尼：平滑速度、角速度和开伞力响应，不改变输入输出；
StepOpen：延长两次充气之间的保持时间；
n_ks：延长第二次充气过程。
```

`deploy_delay` 作为备用方案保留。这样既满足当前“不改输入输出、让结果更好看”的要求，也为后续需要严格延后开伞时序保留扩展路径。不得通过修改主伞面积、阻力系数或质量参数来间接改变开伞过程。
