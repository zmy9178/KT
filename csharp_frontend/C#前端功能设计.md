# C# 前端功能设计

## 1. 项目定位

软件名称：空降特种车辆空投过程仿真与评估 V2026.1。

本前端使用 C# 开发 Windows 桌面软件，面向空降特种车辆空投过程仿真、参数配置、结果展示、模型修正和适应性评估。前端负责界面、数据录入、文件管理、结果读取和可视化展示；动力学计算沿用现有 Python 仿真程序。

当前阶段优先完成可运行的工程闭环：

1. 用户在 C# 前端录入或选择车辆、伞具、环境和仿真参数；
2. 前端将参数写入交换目录；
3. 前端调用 Python 脚本执行仿真；
4. Python 输出结果数据和状态文件；
5. 前端读取结果并展示表格、曲线和关键指标。

| 项目 | 约定 |

## 4. 总体导航结构

软件采用“登录页 -> 主界面 -> 功能模块页 -> 参数弹窗/结果页”的结构。

```text
登录页
  -> 主界面
      -> 出舱过程仿真
      -> 空降过程仿真
      -> 着陆缓冲过程仿真
      -> 着陆缓冲等效建模
      -> 模型准确度标定与修正
      -> 空投适应性评估
      -> 空投过程可视化
      -> 软件配置 / 用户管理
```

主界面功能入口参考原型中的六边形模块布局：

| 模块 | 说明 |
|---|---|
| 出舱过程仿真 | 车辆从机舱滑移、转动、完成出舱的阶段仿真 |
| 空降过程仿真 | 出舱后减速伞、主伞、稳降阶段的完整流程仿真 |
| 着陆缓冲过程仿真 | 车辆着陆冲击和缓冲响应仿真 |
| 着陆缓冲等效建模 | 建立或选择缓冲系统等效模型 |
| 模型准确度标定与修正 | 试验数据导入、测点设置、模型参数修正 |
| 空投适应性评估 | 多工况、阈值、成功率和风险指标评估 |
| 空投过程可视化 | 展示空投全过程轨迹、姿态和关键状态动画 |

## 7. 出舱过程仿真页

### 7.1 页面目标

用于选择空降车辆模型和牵引伞模型，设置出舱阶段仿真参数，运行第一阶段仿真，并展示出舱过程曲线和表格。

### 7.2 页面组成

| 区域 | 内容 |
|---|---|
| 空降车仿真模型选择 | A 车、B 车等车辆模型列表 |
| 牵引伞仿真模型选择 | 牵引伞模型列表 |
| 曲线选择 | x/y 位移、x/y 速度、俯仰角、俯仰角速度等 |
| 仿真数据表格 | 第一阶段输出数据表 |
| 参数设置 | 仿真时间、仿真步长 |
| 操作按钮 | 新建、编辑、删除、选择、保存、开始仿真、出舱过程可视化 |

### 7.3 输入参数映射

出舱过程仿真对应当前 Python 第一阶段输入：

```text
vel_p,qys_p,sim_p
```

车辆参数 `vel_p` 由车辆模型弹窗维护；牵引伞参数 `qys_p` 由牵引伞模型弹窗维护；仿真时间和步长由页面直接录入。

### 7.4 输出数据

读取：

```text
airdrop_output_first.csv
```

展示列：

```text
x_position,y_position,x_velocity,y_velocity,pitch_angle,roll_angle
```

注意：当前模型未独立计算侧倾角时，`roll_angle` 可暂时显示为 0，并在文档或界面状态中注明。

## 8. 空降过程仿真页

### 8.1 页面目标

用于完成空投后续阶段仿真，包括环境参数、减速伞参数、主伞参数设置，以及完整空降过程结果展示。

### 8.2 页面组成

| 区域 | 内容 |
|---|---|
| 主伞参数设置 | 主伞模型列表，新建、编辑、删除、选择 |
| 减速伞参数设置 | 减速伞模型列表，新建、编辑、删除、选择 |
| 曲线选择 | 位移、速度、姿态角、过载变化曲线等 |
| 仿真结果展示 | 着陆末速度、纵/横/垂向末速度、最大过载、姿态角等 |
| 仿真工况设置 | 仿真时间、仿真步长 |
| 空投环境参数设置 | 着陆场海拔、空投相对高度、地面风速、地面温度等 |

### 8.3 输入参数映射

空降过程仿真对应当前 Python 第二阶段组合输入：

```text
第一阶段文件：vel_p,qys_p,sim_p
第二阶段文件：kte_p,jss_p,zhs_p
```

运行第二阶段时，后端应重新计算完整流程，而不是直接拼接第一阶段输出。

### 8.4 输出数据

读取：

```text
airdrop_output_second.csv
```

展示列：

```text
x_position,y_position,z_position,x_velocity,y_velocity,z_velocity,pitch_angle,roll_angle,yaw_angle
```

当前模型如果没有真实偏航角，`yaw_angle` 暂时显示为 0，不能使用旧输出中的过载列冒充偏航角。
